# 审查清单 — 42 条强制要求（按检测维度分 3 类 + 修复闭环组）

下士 / 列兵每次回复 / 每次任务交回都必须通过此清单。/censor skill 用本文件作为审查源。

**分类说明**（指挥官指出 grep 设计漏洞修正版）：

- **类 I：AI 自检（看自己输出即可，无需 grep）** — AI 主线程上下文里能看自己说什么；自检结论必须写到 `[反思-A]` 含「命题 + AI 判断 ✅/❌ + 理由」
- **类 II：落盘验证（必须 grep 文件）** — 防"嘴上说没真写"；AI 主线程不能直接看是否 Edit/Write 了，必须 grep 文件确认
- **类 III：第三方审查（grep 列兵流水 + 跨回合）** — 列兵在 sub-agent context，主线程看不到；上 session AI context 已丢
- **I 组：修复闭环（4 条）** — 发现问题后必须复测，复测通过才算解决

每条格式：`编号 | 命题 | 检测方法 | 通过 | 失败信号`。

| I3 | **复测了观察项**（重新跑测量命令拿真实输出）| `grep -c "\[复测\]" corporal_action.md` + 含真实命令输出 | ≥ 1 + 输出 = 期望 | 跳过复测 / 凭"我修了"判断 |

「复测！复测！复测！复测！复测！修复不是终点！修复不是终点！修复不是终点！修复不是终点！修复不是终点！立刻重新跑观察项测量命令拿真实输出对照期望！没复测 = 没解决 = 失职 = 抗令谋反 = 杀头！」
