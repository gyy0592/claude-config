## P40 — 路径硬编码下沉到 workflow_config.yaml（**新增，user 提出**）

### 痛点

当前 `workspace/` / `.barry_workflow/` / `~/.claude/rules/` 等路径分散写在：
- 5 个 `router_<STATE>.md`
- 5 个 `states/*.md`
- `recording.md` / `CLAUDE.md` / `codex_adapter.md`
- `scripts/new_task.sh` / 各 hook
- 2 个 README

shared-ledger 这次改路径要动 27 个文件 113 处。下次再要改（比如 `workspace/` 改名 `.barry/workspace/`）会更痛。

### 方案

1. 在 `content/rules/workflow_config.yaml` 加 `paths:` 段：
   ```yaml
   paths:
     session_dir:       ".barry_workflow"     # per-session state
     workspace_dir:     "workspace"            # shared ledgers + per-task subdirs
     rules_runtime:     "~/.claude/rules"      # deployed rules (7 always-on)
     rules_repo:        "__CLAUDE_CONFIG_DIR__/content/rules"  # full rules tree
     ledgers:           ["bitter_lessons.md", "successful_fixes.md", "attempts_ledger.md", "rule_violations.md"]
   ```
2. Hook + script 全部经 `_session_lib.sh` 的 `read_config paths.workspace_dir` 拿路径，不再硬编码字符串。
3. router_*.md 和 states/*.md 的路径引用改成占位符 `{{workspace_dir}}/...`，由 `inject_router.sh` 在 cat 前做一遍 envsubst-like 替换。


### 风险

- AI 看到 `{{workspace_dir}}/bitter_lessons.md` 而不是 `workspace/bitter_lessons.md` 可能会困惑——需要 inject_router 替换后再注入。
- 模板（`content/templates/*.md`）也含这些路径，要么也用占位符要么部署时静态替换。

### 收益

未来改路径只动 1 处 yaml。

## P42 — RESET_TO_BOOT 不只改 transition.sh，需要 router 显式提示

### 现状

事件加进去了，但 AI 在 EXECUTE_LOOP 收到 "用户切了 task" 类信号时，**没有 reliable trigger** 让它去调 RESET_TO_BOOT。Run #2 测试中它绕过去了（在 action.md 写 `[END_DONE]` 然后接新任务，state.md 形式上不动）。

### 方案

session_boot 或 inject_router 在每轮 UserPromptSubmit 检测：
- `workspace/<task>/goal.md` 的 mtime > `state.md` 的 last_transition.at
- 如是 → 注入到 router 顶部：「⚠ goal.md 已更新；如果是任务切换，call `transition.sh RESET_TO_BOOT --reason=task-switch`」
