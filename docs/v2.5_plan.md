# v2.5 — long-task instruction following reinforcement

## 动机

长任务里 router 只在 UserPromptSubmit 注入，AI 跑 50+ 工具调用、过 30 分钟，期间一次 router 都不会重新读，靠开头注入硬撑——会衰减。  
需要常驻、token-阈值触发的"再注入"机制，把 (a) cache + ledger 合规、(b) 当前 state 的关键 instruction、(c) autonomy "不要问用户"、(d) REFLECT 阶段必须调 rebuttal subagent，全部做成 PostToolUse / PreToolUse 触发的 banner。  
全部阈值集中到 `content/rules/workflow_config.yaml`，禁止硬编码。

## token 增量口径（一次性钉死）

`input_tokens + cache_read_input_tokens + cache_creation_input_tokens`——transcript.jsonl 每条 assistant 消息的 `usage` 字段三项之和的累积。这等于每轮"实际喂给模型的 context 长度"，自然包含 user prompt / AI output / tool result。  
**口径已在 `cache_refresh_check.sh` 用，不改。**

## 5 件事（按入侵性从小到大）

### 1. cache_refresh_check.sh：从 UserPromptSubmit 迁到 PostToolUse + 扩 ledger 列表

**问题**：现在挂在 UserPromptSubmit，长任务期间 0 触发。  
**改**：迁到 PostToolUse，每次工具调用后判断累积 token 是否过 200k 阈值。banner 内容扩展为完整 ledger 自检清单：
- `~/.claude/rules/lessons.md` (全局 AI 行为智慧)
- `~/.claude/rules/violation.md` (全局 AI 违规)
- `workspace/bitter_lessons.md` (项目技术坑)
- `workspace/rule_violations.md` (项目 AI 违规)
- `workspace/successful_fixes.md` (项目成功 fix)
- `workspace/attempts_ledger.md` (项目尝试日志)

阈值 yaml key：`cache_refresh.threshold_input_tokens`（保留现值 200000）。  
state file：`$PWD/.barry_workflow/<sid>/cache_refresh.json`（沿用）。

### 2. posttool_state_reinforce.sh（新）：state-aware 短摘要，10k 触发

**问题**：当前 state 的 "Allowed/Forbidden + autonomy + dispatch + recording" 这些只在 UserPromptSubmit 注。  
**改**：PostToolUse hook，每 10k token 增量触发一次，根据当前 state.md 的 `current_status` cat 出对应 `router_<STATE>.md` 的**头部摘要**（< 400 字符），重新注入。  
比 cache_refresh 高频（10k vs 200k），但 payload 也小一个数量级（≤400 字符 vs 几百字）。  
state file：`.barry_workflow/<sid>/state_reinforce.json`。  
yaml key：`state_reinforce.threshold_input_tokens` (默认 10000)、`state_reinforce.max_chars` (默认 400)。

### 3. pretool_reflect_nag.sh（新）：REFLECT 状态 + 未调 Agent → 每次工具调用都注一句

**问题**：进入 REFLECT 后模型常常忘记"必须 spawn rebuttal subagent"，直接写文件或读读就走人。  
**改**：PreToolUse hook，matcher=`*`。检查：
1. 当前 state == REFLECT？
2. 本 session 的 action.md 里有没有出现过 Agent / SendMessage 的工具调用？

两条都 yes（reflect 中 + 还没调过 agent）→ 每次工具调用都注一句 ≤200 字符的提醒：  
> "REFLECT 状态，还没 spawn rebuttal subagent。除非你正在准备 spawn，否则现在该调 Agent(run_in_background=true) 跑 rebuttal，不是写文件。详见 `~/.claude/rules/states/reflect.md`。"

不需要阈值，纯条件触发。yaml key：`reflect_nag.max_chars` (默认 200)、`reflect_nag.enabled` (默认 true)。

### 4. autonomy 提醒：合并到 #2 的 state_reinforce 里，不开独立 hook

**理由**：每个 `router_<STATE>.md` 的 "Always-on" 块里已经有 autonomy 那一行（M2 之后内容是 "never stop, only ask-while-working"）。state_reinforce 注的就是 router 头部摘要，已包含这一句。**不需要重复**。  
如果以后想单独调 autonomy 提醒的频率，加 yaml key `autonomy_nag.threshold_input_tokens` 拆出来再做。当前 v2.5 不拆。
